Overview
This repository contains the preprint:

Transition Graphs of Consecutive Prime Gaps: Observed Missing Transitions and Three Forbidden Cases

The manuscript introduces a graph-theoretic representation of transitions between consecutive prime gaps.

The framework distinguishes between:

observed transitions;
missing transitions;
forbidden transitions.
Three transitions are shown to be impossible:

2 -> 8
2 -> 14
4 -> 10
using elementary modular arguments.

Data Availability
The analyses reported in the manuscript were performed on a privately curated dataset of consecutive prime numbers.

The source dataset is not distributed through this repository.

The manuscript contains all numerical results necessary to understand and verify the conclusions reported in the study.
